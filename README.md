# Moose Crossing

Moose Crossing — an endless hop-forward lane-crossing game. Hop a moose across roads, rails and rivers before the blizzard catches up.

Play: https://play.btownbrief.com/moose-crossing/

Part of Btown Games (https://play.btownbrief.com). Plain static site, no build step; pushing to `main` deploys GitHub Pages.
